# Snowball Pilot

**场外雪球、凤凰合约的持仓管理工具**

盯市、预警、事件跟踪、事后对账，一处搞定。

---

## 这是什么

你手上管着几十笔场外合约——雪球、凤凰。它们的条款各不相同：什么时候敲出、敲出线在哪、什么时候派息、派息线在哪、保证金留多少。

这些条款一旦记错、漏记一次观察日，损失就是真金白银。

Snowball Pilot 把这些条款录进去，之后所有数字自动算、所有日子自动提醒、所有记错的地方自动挑出来。你只需要看它指出来的地方。

- **数据存在你自己电脑上**，不联网也能用，不上传任何合约信息
- **行情自动获取**，价格、指数、敲入敲出状态自动更新
- **每天打开就知道该看哪几笔**

---

## 八个功能

### 投资总览 — 今天打开第一眼

四张卡：名义本金、保证金、合约数、已了结收益。每张都分「存续中」和「累计」，一眼看出当前敞口和历史赚亏。

下面是四大宽基指数的实时行情和涨跌幅，可以设置 10 秒到 5 分钟自动刷新。

最下面是**预警看板**：所有快要出事——快敲出、快派息、快敲入——的合约都排在上面，鼠标点进去直接看详情。不用自己翻。

### 事件日历 — 今天是几号，该看哪几笔

月历上直接标出全部合约的关键日子：

- 绿色 = 敲出观察日
- 蓝色 = 派息观察日

每个事件都写着标的、合约编号、障碍价。点一下跳到持仓详情。

早上打开日历，今天要盯什么一目了然。

### 持仓管理 — 所有合约一张表

按需排序，默认只显示存续中的，随时切到含已了结的全部。

每笔合约实时显示：当前价、下一个敲出日是哪天、那天要看什么价位、**安全垫还有多少**、现在赚还是亏。

**安全垫**是最该盯的数——现价离敲入线还有多少空间。快归零了，价格再跌一点就敲入，20% 保证金限亏就锁死了。

### 合约录入与跟踪 — 录进去，之后全自动

**两种录入方式：**

- **填表**：雪球和凤凰各一套表单，按结构只显示该结构的条款
- **粘贴导入**：把券商发来的合约要素文本直接粘进去，自动识别是雪球还是凤凰，自动拆分敲出日和障碍价、敲入条款、保证金、返息费用。识别不了的字段会明确提示「已忽略」，不会悄悄丢掉

**管得动的条款：**

- 敲出：观察日、障碍价、票息、敲出增强参与率、到期票息
- 敲入：观察方式（每日 / 到期）、敲入线、执行价、参与率
- 保证金比例、最大亏损比例
- 凤凰专属：派息障碍、派息观察日、派息率
- 费用返息：绝对费用、年化费用、收益分红、前后端返息、计息规则、结算 T+

**状态流转：**

- 标记敲入 / 发现记错了撤销掉
- 登记敲出、登记到期，填了结日期和实际收益，自动算出赚了多少
- 凤凰派息登记，金额和支付日记一笔，计入总收益

改错了随时能改能撤销，不会留错记录。

**持仓结构图**：期初价、敲入线、敲出障碍、派息线、当前价画在同一张图上。安全垫多厚、离下一道障碍还有多远，不用算，看图就知道。

### 持仓分析 — 风险在哪

- **按标的环形图**：本金压在哪个标的上，有没有过度集中
- **按结构环形图**：雪球和凤凰各占多少
- **风险散点图**：横轴安全垫，纵轴本金规模。**越靠右下越危险**——安全垫薄、规模又大，那几笔就是真正要盯的。点一下直达详情

### 合约检查 — 专门抓你记错的地方

拿历史行情和合约条款自动对账，查出四类问题：

| 问题 | 什么意思 |
|---|---|
| **漏记敲出** | 那天价格明明够敲出线了，但你没记 |
| **漏记派息** | 那天价格明明够派息了，但你没记 |
| **误记敲出** | 你记了敲出，但那天价格其实没到敲出线 |
| **误记派息** | 你记了派息，但那天价格其实没到派息线 |

每一笔都列出日期、障碍价、当天实际收盘价、差多少，点进去就能改。

这是**事后对账工具**——用来补漏和纠错，不是每天要看的东西，但出问题时它能直接告诉你问题在哪。

### 标的管理 — 行情数据维护

- 加删你要跟踪的指数 / 标的
- 每个标的的最新价、日/周/月/年涨跌（自动按区间高低点着色）
- **K 线图**，看历史走势随时切换
- **标的回溯**：拉近两年历史数据，新增标的第一天就自动补全

### 预警设置 — 提前量由你定

四个阈值自己调：敲出提前几天开始提示、离敲出线多近提示、离派息线多近提示、离敲入线多近提示。

**改参数时立刻能看到当前会触发哪些合约**，不用等。设好了打开桌面通知，到点主动弹窗。

## 还需要知道的

- **自动更新**：新版本自动下载安装，不用手动升级
- **离线可用**：历史行情存在本地，断网时合约检查、持仓分析、日历照常用
- **界面**：明暗两套主题，随时切换
- **多账号**：每个账号的数据相互独立，互不可见

---

## 快速上手建议

1. 登录后先进「标的」，把常跟的指数加进去，等历史数据回填完成
2. 进「持仓管理」，把在手的合约录进来（优先用粘贴导入，快得多）
3. 进「预警设置」，按你的风险偏好调四个阈值
4. 以后每天：先看「投资总览」预警，再看「事件日历」今天有没有事
5. 每季度末或了结一批后，跑一次「合约检查」补漏纠错
