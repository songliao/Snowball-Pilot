## TestFlight 粘贴版

```
本版统一了「敲入」的处理口径（与桌面端一致），并新增三项能力：
1. 已敲入仍属存续：总览的名义本金/保证金/合约数与持仓分析均计入已敲入合约，不再因敲入而减少。
2. 敲入后不再显示「敲入浮亏」：详情页与持仓列表不再按现价估算浮亏。
3. 总览新增「已敲入合约」卡片：单独展示已敲入合约的名义本金与保证金合计。
4. 合约检查新增「漏记敲入 / 误记敲入 / 敲入日期不符」三类对账结果（敲入日期不符=标记日期与实际跌破障碍价的观察日不一致；到期观察的合约只认到期日）。
5. 已敲入的合约不再重复预警敲入（敲出/派息预警仍正常）。

建议重点测试：标记敲入后总览统计不变且新卡片数字正确；合约检查能发现日期标错的已敲入合约；桌面端详情页「复制合约」的文本粘贴到 iOS「导入交易」可完整回填。
数据只存本机，测试前建议先在「持仓 → 导出 CSV」备份。
```

## 详细测试清单（内部测试用）

### 准备

- 数据源：正式用户库即可；空库可用 DEBUG 演示模式（Xcode/simctl 启动参数 `-demoMode`）。
- 需要至少一条**存续中**的合约（雪球、凤凰各一条更佳），且其标的有行情（详情页点「获取实时价」，或标的管理里更新过）。
- 敲入障碍价 = 期初价格 × 敲入障碍比例（如期初 6213.44、障碍 75% → 4660.08），验证时按此换算。

### 1. 已敲入仍属存续（总览 + 分析）

| 步骤 | 预期 |
|---|---|
| 记下总览四卡的名义本金/保证金/合约数（含「全部」小字） | 记为基线 |
| 持仓列表 → 存续合约详情 → 右上菜单「标记敲入」→ 确认 | 状态标签变橙色「已敲入」，头部出现敲入日期行 |
| 回总览页看四卡 | 名义本金/保证金/合约数与基线**一致**（不因敲入减少）；「全部」数不变 |
| 更多 → 持仓分析 | 环形图、风险散点仍包含这条已敲入合约 |
| 持仓列表切「存续 / 已敲入 / 全部」筛选 | 已敲入合约同时出现在「存续」与「已敲入」里（与改动前一致） |

### 2. 敲入后不算浮亏

| 步骤 | 预期 |
|---|---|
| 进入已敲入合约详情，获取实时价 | 实时行情卡**不再出现「敲入浮亏」行**（安全垫、敲出/派息价行仍正常） |
| 回持仓列表看这条合约的行右侧 | **不再显示「敲入浮亏 x」角标**；现价与安全垫仍显示 |
| 对照：把现价调到低于期初价（等行情变化或换合约） | 依旧无浮亏展示——这是有意为之，不是漏算 |

### 3. 合约检查含敲入规则

| 步骤 | 预期 |
|---|---|
| 更多 → 合约检查 → 开始检查 | 分组从四类变六类（顺序：漏记敲出/漏记敲入/漏记派息/误记敲出/误记敲入/误记派息） |
| 找一条**未敲入**、且历史行情跌破过敲入障碍价的存续合约 | 应出现在「**漏记敲入**」，观察日为最早跌破那天，收盘价绿显 |
| 找一条已标记敲入、但观察期内从未跌破障碍价的合约 | 应出现在「**误记敲入**」（参考最近观察日） |
| 已敲入且确实跌破过障碍价的合约 | 不应报「误记敲入」 |
| 点问题行的「添加备注」 | 预填摘要含「最大亏损 = 名义本金 × 最大亏损比例」一行 |
| 每日观察 vs 到期观察两种合约分别试 | 每日观察按起息日以来每个行情日判定；到期观察只看到期日（最后一个敲出观察日） |

### 4. 已敲入不再预警敲入

| 步骤 | 预期 |
|---|---|
| 让已敲入合约的现价低于敲入障碍价（等行情，或挑已深跌的合约），刷新总览 | 「合约预警」里该合约**不再出现**「已跌破敲入线 / 逼近敲入线」理由 |
| 同一合约若有未来敲出观察日且现价临近敲出线 | 敲出预警理由**仍在**（已敲入不妨碍后续敲出） |
| 未敲入的存续合约跌破敲入线 | 仍正常报敲入预警（行为不变） |
| 预警通知（可选）：等前台 5 分钟检查周期 | 本地通知同样不含已敲入合约的敲入理由 |

### 5. 总览「已敲入合约」卡片

| 步骤 | 预期 |
|---|---|
| 看总览统计区 | 合约数右侧多一张「已敲入合约」卡（主值=已敲入名义本金合计，副值=保证金合计） |
| 标记一条合约敲入后回总览 | 该卡数字增加该合约的本金与保证金；上方存续四卡不变（口径独立） |
| 撤销敲入 | 该卡数字回落，存续四卡不变 |

### 6. 合约检查「敲入日期不符」

| 步骤 | 预期 |
|---|---|
| 已敲入合约的敲入日期与实际跌破日一致 | 不报 |
| 详情页「撤销敲入」后重新标记，故意选一个没跌破的日期 | 「敲入日期不符」分组出现该合约：显示实际跌破日收盘，行内橙字标注「敲入标记日 X」，收盘红显 |
| 已敲入但未记录日期（桌面端旧数据允许空日期） | 报「敲入日期不符」，备注注明「未记录敲入日期」 |
| 到期观察的合约标记敲入 | 日期核对只认到期日（最后一个敲出观察日）：标记日≠到期日即报；到期日未跌破则归入「误记敲入」 |
| 点「添加备注」 | 摘要含「敲入标记日 / 实际跌破日」两行与最大亏损金额 |

### 7. 与桌面端单笔互通（桌面端同期新增「复制合约」按钮）

| 步骤 | 预期 |
|---|---|
| 桌面端合约详情 → 「复制合约」 | 提示已复制；文本为标准要素格式（产品名称/结构类型/敲出观察日…） |
| iOS 新建持仓 → 粘贴导入该文本 | 要素完整回填、无「未识别字段」提示（含年化费用/收益分红/产品名称） |
| iOS 详情页菜单「复制合约」→ 桌面端新建持仓「导入交易」粘贴 | 同样完整回填（反向互通） |
| 修改几个字段再复制粘贴 | 已填字段按粘贴文本覆盖，与表单语义一致 |

### 8. 回归清单

- [ ] 详情页菜单「撤销敲入」：状态回「存续中」、敲入日期清空，总览统计与预警行为恢复
- [ ] 敲出/到期了结登记照常；了结后合约进「已了结」筛选，总览「已了结收益」口径不变
- [ ] 凤凰「派息登记」照常；合约检查的漏记/误记派息两类不受影响
- [ ] CSV 导入导出照常（与桌面端互通，两端口径已一致）
- [ ] 桌面端同期更新：两端对同一合约敲入后，总览统计、合约检查结果应一致（可对照验证）

## 注意事项

- 合约检查与预警都依赖**已入库行情**：新标的先在标的管理里「下载历史行情数据」。
- 敲入障碍价是**比例小数**存库（0.75 = 75%），核对数值时别按百分数换算两遍。
- 本版不涉及数据库结构变更，老数据升级后直接可用。
